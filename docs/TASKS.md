  * 상의·하의 종류와 주요 색상을 추정한다.
  * 각 결과에 신뢰도 점수를 포함한다.

  완료 조건

  * 사람별 외형 분석 결과가 구조화된 값으로 반환된다.

  운영 참고

  * `openai/clip-vit-base-patch32` 모델은 외형 분석 기능을 처음 실행할 때 자동으로 다운로드되고 이후에는 로컬 캐시를 재사용한다.
  * 최초 다운로드에는 인터넷 연결과 약 600MB의 다운로드 용량이 필요하다.
  * 저장 공간은 최소 1GB의 여유 공간을 권장한다.
  * 시스템 메모리는 최소 4GB, 권장 8GB 이상을 기준으로 한다.
  * CPU에서도 실행할 수 있지만 YOLO와 동시에 사용하면 실시간 처리 속도가 느려질 수 있다.
  * NVIDIA GPU 사용 시 VRAM 4GB 이상을 권장한다.
  * 성능이 부족하면 모든 프레임을 분석하지 않고 일정한 프레임 간격으로 외형 분석을 실행한다.
